# Contributing

Описывайте ожидаемое поведение, способ воспроизведения и границы проверки. Следуйте AGENTS.md и docs/process/documentation-governance.md. Не добавляйте секреты, kubeconfig, backups, локальные дампы и credentials. Новые зависимости должны быть нужны конкретному сценарию.

Проверки: go test ./..., go test -race ./..., go vet ./..., профильные команды Taskfile. Не запускайте разрушительные сценарии на чужом кластере; сохраняйте данные восстановления. Исторические результаты не выдавайте за проверку нового изменения.

## Заголовки Git-коммитов

Все заголовки коммитов (первая строка) пишутся на русском языке, кратко и содержательно описывают конкретное изменение. Названия технологий, пакетов и идентификаторы (Go, Kubernetes, Helm, Kafka, PostgreSQL) допускаются без перевода. Тело сообщения также предпочтительно писать на русском. Технические префиксы Conventional Commits необязательны; при их использовании текст после префикса всё равно должен быть русским. Например: «Исправлено завершение Kafka worker». Исторические SHA и авторство не переписывать.
