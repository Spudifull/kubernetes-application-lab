# Security reporting

Это учебный стенд, не production-платформа и не программа bug bounty. Не публикуйте действующие токены, пароли, ключи или полный kubeconfig в issue.

Если GitHub Private Vulnerability Reporting включён владельцем, используйте Security → Report a vulnerability. Если пункт недоступен, создайте issue только с просьбой предоставить приватный канал без технических подробностей или секретов. После получения согласованного канала передайте минимальное воспроизведение. Сроки ответа и поддержка всех исторических версий не гарантируются.
