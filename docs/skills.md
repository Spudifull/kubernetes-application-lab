# Необязательные внешние навыки

Для Go, Docker, Task, Helm и лабораторных опытов навыки агента не требуются. Содержимое навыков не включено в снимок; правила проекта находятся в AGENTS.md. Публичные источники и точные SHA перечислены в skills.lock.json; приватных credentials не требуется.

Автоматическая синхронизация Bash/Python исключена. Перенос синхронизации в Go отложен, чтобы не вводить дополнительную систему зависимостей в публикационную миграцию. Безопасный ручной способ для любого элемента lock:

1. Создать новую временную директорию вне проекта. Не использовать существующий каталог с пользовательскими файлами.
2. Клонировать указанный публичный HTTPS source через Git с GIT_TERMINAL_PROMPT=0; fetch --depth=1 origin точного commit из lock.
3. Проверить rev-parse FETCH_HEAD: он должен в точности совпасть с pinned SHA. Просмотреть SKILL.md, root LICENSE и требуемые notices на этом SHA.
4. Взять только указанный path вместе с upstream LICENSE/notices. Для path=. исключить .git; перенести только SKILL.md, README.md, references/scripts/templates и LICENSE.
5. Если destination уже существует, остановиться: не удалять и не перезаписывать его автоматически. Скопировать в новый destination только после просмотра.
6. Сохранить неизменные notices и лицензию; при локальных изменениях учитывать условия MIT/MPL-2.0.

Установленные внешние каталоги игнорируются Git. Копии внешних навыков и их потенциально небезопасные примеры не входят в публикационный снимок. Для разработки действуют [AGENTS.md](../AGENTS.md) и [CONTRIBUTING.md](../CONTRIBUTING.md).
