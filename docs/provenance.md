# Происхождение публичного снимка

Проект первоначально развивался в приватном репозитории. История предназначенной для публикации версии начинается с отдельного корневого коммита `3175c49618f4d811d73aedbe8ea28a34c7cc902a`. Исходный снимок соответствует приватной ревизии `a8cf93bcc3c4a6316550a58e009d3406f80cd599`.

Milestones 1–8 проверялись до экспорта. SHA, revision образов, даты и измерения в исторических отчётах сохранены; они не обозначают коммиты нового Git root и не означают повторного выполнения снимка. Ссылок на отсутствующие публичные коммиты не создаётся.

В [индексе доказательств](verification/README.md#первичные-доказательства-milestone-8) опубликованы 21 JSON и 1 TXT: 20 Original и 2 Sanitized. В двух файлах заменён пользовательский путь в PowerShell prompt; исходные и публичные SHA-256 и схема очистки приведены в индексе. Приватные оригиналы сохранены отдельно. Исходные attachment dumps не опубликованы.

Все 26 PNG сохранены с исходными датами и ссылками. Учебные ClusterIP, PodIP, Service DNS, namespace, job/event/trace ID и SHA сохранены для понимания механизмов. Повторное подтверждение поведения требует собственного прогона, образов и отчёта.

Версия содержит отобранные доказательства и не обязана включать весь приватный диагностический архив. Сторонние установленные навыки не включены; корневая MIT не переопределяет их лицензии. Лицензионные notices сохранены.

Локальный lab-workflow также исключён консервативно: в его исходном frontmatter указана внутренняя лицензия. Содержимое не перелицензировано автоматически; для возвращения файла потребуется явное решение правообладателя. Это не влияет на выполнение стенда.
