# Происхождение публичного снимка

Публичный снимок подготовлен из зафиксированного dev HEAD a8cf93bcc3c4a6316550a58e009d3406f80cd599 приватной разработки. В оригинале 99 доступных коммитов. Исходная история остаётся у владельца и в публичный каталог не переносится; будущая история main начинается отдельным релизным коммитом после одобрения.

Milestones 1–8 проверялись до экспорта. SHA, revision образов, даты и измерения в исторических отчётах сохранены; они не обозначают коммиты нового Git root и не означают повторного выполнения снимка. Ссылок на отсутствующие публичные коммиты не создаётся.

Сырые docs/verification/evidence JSON оставлены в приватном архиве; их ссылки заменены пояснениями. Все 26 PNG из docs/verification/images проверены индивидуально и включены с исходными датами и ссылками. Личные данные и секреты в видимых областях не обнаружены; редактирование пикселей не потребовалось. При экспорте удаляются текстовые, EXIF и временные metadata PNG, если они присутствуют; данные изображения и цветовые характеристики сохраняются. Тексты описывают воспроизводимые процедуры, результаты и ограничения; без первичного архива независимая проверка исторических измерений ограничена. Пути пользовательской машины отредактированы и не являются исходным измерением. Учебные ClusterIP, PodIP, Service DNS, namespace, job/event/trace ID и SHA не являются credentials; сохранены для понимания механизмов. Повторное применение схемы требует собственного прогона, образов и отчёта.

Удалены приватные и установленные сторонние agent skills. Их лицензии не переопределены корневой MIT. Отдельный transfer manifest и аудит предназначены владельцу и находятся вне публичного каталога.

Локальный lab-workflow также исключён консервативно: в его исходном frontmatter указана внутренняя лицензия. Содержимое не перелицензировано автоматически; для возвращения файла потребуется явное решение правообладателя. Это не влияет на выполнение стенда.
