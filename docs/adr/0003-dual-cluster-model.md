# ADR-0003: Две Kubernetes-среды

- Статус: Accepted
- Дата: 2026-10-04

## Контекст

Для большинства сценариев уровня приложения нужен быстрый и воспроизводимый кластер. Для изучения узлов и `control plane` позднее требуется среда, где инфраструктура не скрыта контейнерным локальным кластером.

## Решение

Использовать:

- `kind` — основная локальная и CI-среда;
- самостоятельно управляемый кластер из нескольких узлов на `kubeadm` — поздний этап.

Helm chart приложения должен оставаться общим, пока реальное различие сред не потребует иного.

## Альтернативы

- Сразу начать с `kubeadm`.
- Использовать только `kind`.

## Последствия

Разработка приложения и Helm не зависит от Terraform и виртуальных машин.

Поздний кластер добавляет знания уровня узлов без переписывания модели поставки приложения.

## Проверка соблюдения

Отсутствие `kubeadm` не должно блокировать сценарии уровня `Pod`, `Deployment`, `Service`, проверок состояния, HPA и Helm.
