# ADR-0002: Границы поставки приложения и инфраструктуры

- Статус: Accepted
- Дата: 2026-10-04

## Контекст

Terraform, Helm и GitOps-контроллеры способны пересекаться в управлении ресурсами. Несколько владельцев одного объекта создают конфликт жизненных циклов и затрудняют объяснение результата.

## Решение

Разделить ответственность:

```text
Terraform → сеть, VM, диски и базовая инфраструктура
Helm      → Kubernetes-ресурсы приложения
GitOps    → выбранная версия состояния среды
```

На раннем этапе GitOps отсутствует, но будущая
граница фиксируется заранее.

## Альтернативы

- Управлять `Deployment` и `Service` через Terraform.
- Оставить только обычные YAML-манифесты.
- Отказаться от GitOps.

## Последствия

Инструменты демонстрируют разные уровни системы без борьбы за один ресурс.

Изменение границы требует отдельного решения.

## Проверка соблюдения

Объекты приложения не должны одновременно иметь независимое управление через Terraform и Helm.
