# ADR-0001: Отдельный Kubernetes-стенд

- Статус: Accepted
- Дата: 2026-10-04

## Контекст

Kubernetes нужен как отдельная область практики и как доказательство навыков развёртывания серверных приложений. Продуктовый репозиторий не должен получать инфраструктурную сложность до появления собственной продуктовой необходимости.

## Решение

Развивать Kubernetes Application Lab как отдельный репозиторий.

Серверное приложение внутри него намеренно минимален и служит управляемым `workload`.

## Альтернативы

- Добавить весь Kubernetes-план в another private engineering project.
- Ограничиться несколькими несвязанными YAML-примерами.

## Последствия

В лаборатории допустимы искусственные отказы, нагрузочные маршрут и эксперименты, которые были бы неуместны в продукте.

Необходимо отдельно следить, чтобы разработка приложения не стала самоцелью.

## Проверка соблюдения

Новая функциональность приложения должна быть связана с конкретным Kubernetes-сценарием или измеряемым эксплуатационным свойством.
