# Цикл разработки и проверки

**Состояние: Current.**

Процесс отделяет архитектурное решение, реализацию и доказательство поведения.

## Роли

- **Владелец** принимает решения, меняющие долговечные границы проекта.
- **Агент-исполнитель** работает в пределах брифа и точно фиксирует выполненные проверки.
- **Ревьюер** сопоставляет результат с текущим контрактом и критериями приёмки.

## Когда требуется отдельное решение

Агент не должен закреплять архитектуру случайной реализацией, если задача требует выбрать долговечную границу.

Примеры: обычный `Job` или Helm hook для миграций, конкретный CNI, владелец ресурсов между Terraform и GitOps, конкретная очередь или конкретное хранилище телеметрии.

До решения владельца такой вопрос остаётся `Blocked`.

## Отчёт агента

Итоговый отчёт содержит изменённые файлы, прочитанные проектные навыки, правила, которые повлияли на реализацию, выполненные проверки, непроверенные свойства, оставшиеся риски и решения, требующие владельца.
