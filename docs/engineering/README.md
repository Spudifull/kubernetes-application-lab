# Инженерные инструкции

В этом разделе собраны процедуры для запуска стенда, проверки компонентов и воспроизведения лабораторных экспериментов. Инструкции описывают необходимые условия, порядок действий и ожидаемое поведение системы.

Команды определены в `Taskfile.yml` и вспомогательных утилитах проекта. Перед выполнением сценария проверьте указанный контекст Kubernetes и ограничения на изменение ресурсов. Результаты ранее проведённых экспериментов находятся в [каталоге проверок](../verification/README.md).
