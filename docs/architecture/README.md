# Архитектура стенда

Этот раздел объясняет устройство Kubernetes Application Lab и распределение ответственности между приложением, контейнерами, Kubernetes и инфраструктурой. Здесь описаны общие принципы; настройки отдельных компонентов приведены в проектных контрактах.

## Документы

| Документ | Содержание |
|---|---|
| [Системная архитектура](system-architecture.md) | Состав системы, взаимодействие компонентов, границы ответственности и варианты окружений. |
| [Эксплуатационная архитектура](operational-architecture.md) | Развёртывание, обновление, завершение процессов, восстановление после отказов, масштабирование и диагностика. |

Многонодовые сценарии вынесены в отдельный [проектный документ](../design/multi-node-kubernetes.md). Процедура для отдельных виртуальных машин описана в [инструкции по `kubeadm`](../engineering/kubeadm-hyperv-lab.md).

- [Проектные контракты](../design/README.md) — правила работы компонентов, инварианты и ограничения реализации.
- [Инженерные инструкции](../engineering/README.md) — последовательности команд для запуска и воспроизведения экспериментов.
- [Результаты проверок](../verification/README.md) — фактические наблюдения, использованные конфигурации и границы выводов.
- [Архитектурные решения](../adr/README.md) — причины выбора подходов и рассмотренные альтернативы.
